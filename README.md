# PSlatencytester
Powershell GUI latency tester<br />
Requires [Powershell 7](https://github.com/PowerShell/PowerShell)<br /><br />
A more advanced version of [PSpingtester](https://github.com/aigles1/PSpingtester) made with [Claude](https://claude.com).<br />
Includes Stop, Pause, Resume and Ctrl+C support. Ctrl+C is captured on the console and behaves the same as pressing Stop.<br /><br />
For a world ping test within your browser, I recommend [Meter.net World Ping Test](https://www.meter.net/tools/world-ping-test)
